# 文齐液态玻璃桌面界面

## 设计

新版将主要任务放在“文档”和“格式”两个工作区。文档页保留文件列表、处理方式、格式选择、保存位置与格式预览；格式页提供完整的段落参数表，以及页面、表格和处理选项。启动公告、版权页脚、重复的操作卡片和长篇说明退出主页面。关于和许可证信息保留在菜单里，运行日志按需查看。

配色：冰蓝背景 `#e9eef6`、纸白 `#ffffff`、墨色 `#202839`、辅助灰 `#768092`、操作蓝 `#2676f5`。中文使用系统无衬线字体，Windows 优先 Microsoft YaHei UI，macOS 使用 PingFang SC；正文预览使用用户选择的文档字体。正文内容保持清晰纸面，玻璃用于导航、文件接收区、操作条和浮层。

玻璃包含真实背景模糊、饱和度调整、凸面边缘位移、内侧高光和柔和阴影。位移图由 JavaScript 根据每个控件的尺寸和圆角生成，边缘折射，中央保持稳定。尺寸变化后通过 ResizeObserver 重建；系统的减少动态效果偏好会关闭过渡与入场动画。

依据：[Apple Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。

## 实现

- `ui/index.html`：语义页面与面板结构，本地图标，无远程素材。
- `ui/styles.css`：玻璃材质、排版、响应式布局与键盘焦点。
- `ui/app.js`：页面切换、参数编辑、预览、状态轮询、结果与浮层。
- `scripts/desktop_ui.py`：pywebview 窗口、原生选择文件、文件拖拽、预设模型、后台处理与结果打开。
- `docformat_gui.py`：默认启动新界面；Python 3.8 / Win7 保留 Tk 界面。现有配置函数继续作为共享模型。

所有文档工作在本地。HTML 和脚本随程序打包，未引入 CDN、在线字体或远程请求。pywebview 可为本地页面启动回环 HTTP 服务，用于加载本地资源。文档处理继续调用现有 formatter、punctuation、analyzer、converter。

编辑参数采用现有“基准值 + 覆盖值”模型，自动保存并允许单行/全部恢复。保存新格式会生成独立快照。内置格式不会写入用户配置。已有同名输出文件会自动追加序号，原文件不能作为输出目标。

字体选择使用统一的搜索浮层，段落、表格和页码均可打开完整字体列表。搜索框独立于已选字体，避免原生 datalist 根据当前值过滤到只剩一项。支持中英文名称搜索、方向键和 Enter 选择、Escape 关闭，以及手动输入与清空恢复默认；浮层在窗口内定位，页面切换或滚动时收起。

段落对齐、页码样式、页码位置、空格处理和主页面的格式选择均使用同一个选择控件，与字体菜单共用玻璃浮层、选项高亮和选中勾选样式。隐藏的原生 select 保留参数值与现有自动保存流程，可见按钮支持方向键、Home/End、Enter/空格确认和 Escape 关闭；菜单互斥，点击外部、切换页面、滚动或缩放窗口时收起。参数表和设置表单各自保留原有控件高度，长列表可滚动。

文本输入在独立浮层中生成实际 `.docx`，加入处理队列；临时输入在窗口关闭时清理，输出默认落在 Documents 文件夹。批量任务可在当前文件完成后停止。错误、部分失败和诊断结果在页面内展示，不再连发完成提示框。

## 验证

`python -m pytest -q` 验证现有排版内核和新增桌面流程。新增测试覆盖参数保存/恢复、自定义格式、三种处理方式、输入保护、输出避让、失败释放任务、粘贴文本及取消批处理。

`python prototype/_check_glass_ui.py` 在 Windows 启动真实 WebView2 窗口，检查桥接、原生拖拽监听注册、DOM 拖拽事件至 Python 的路径、真实文档输出、结果页面、参数编辑和 800×640 窗口布局，并抓取截图。合成事件无法创建操作系统的真实文件句柄，所以该检查为拖拽预置路径缓存；原生文件句柄获取需要实际从资源管理器拖入验证。

Windows 打包通过 `python build.py windows`。构建检查前端入口与 pywebview 依赖，收集 ui、WebView2 桥接 DLL、pythonnet 和 clr-loader。Windows 10/11 需要可用的 WebView2 Runtime。macOS 使用系统 WKWebView；Linux 需要 GTK / WebKitGTK 与 PyGObject。旧 Win7 构建继续使用 requirements-win7.txt。

打包后可安装 `websockets` 并运行 `python prototype/_check_glass_exe.py`，也可传入指定 EXE 路径。检查仅对自己的子进程启用临时 CDP 端口，并以临时 APPDATA 隔离配置；验证真实打包界面的桥接、材质、11 个元素、全部设置页、原作者归属、文档处理和结果操作可见性。字体检查使用真实浏览器鼠标与键盘输入，覆盖完整列表、中英文搜索、全部字体字段、自动保存、手动输入、清空恢复、小窗口浮层边界及实际输出文档字体。

## Windows 窗口行为

`scripts/window_controls.py` 为无边框壳恢复原生窗口样式、尺寸约束与 Windows 移动/缩放循环。最大化时将可见客户区限制在当前显示器工作区；最小化后同步 WebView 子窗口的真实位置，避免偏离主窗口。窗口按钮读取系统真实状态，标题栏按钮不参与拖动。四边和四角的透明命中区域进入原生缩放循环，保留系统最小尺寸和 DPI 坐标处理；双击标题栏可最大化、还原。

`python prototype/_check_window_controls.py` 使用隔离配置检查最大化工作区、反复还原的尺寸、任务栏恢复、实际鼠标拖动八个边缘/角、标题栏拖动、三个窗口按钮以及双击。鼠标注入前检查目标属于测试窗口，结束后恢复鼠标位置。
