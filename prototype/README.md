正式方案见 [`../docs/ARCHITECTURE.md`](../docs/ARCHITECTURE.md) 第 3.3 节。

**纯视觉原型，不处理任何真实文档**，点「选择文件」「开始处理」只会弹提示框。

## layout_b.py — 格式编辑内联 + 预设作起点

```bash
python prototype/layout_b.py
```

- 格式编辑区**直接内联在主页面**，不再是弹窗
- 左侧一列**起始格式**作为起点，点击即把参数装载进右侧参数表
- 右侧是**元素参数表**：一行一个元素（主标题 / 主送机关 / 一~四级标题 / 正文 / 落款 /
  成文日期 / 附件说明），列为各参数：

  | 中文字体 | 英数字体 | 字号 | 加粗 | 对齐 | 首行缩进 | 行距 | 段前 | 段后 |
  |---|---|---|---|---|---|---|---|---|

### 左列：预设，带边框的滚动面板

左列把**起始格式**和**我的格式**放在一起，同一个 `PresetOption` 组件、同样的行样式，
整体包在一个带边框的滚动面板里。**出厂只有 4 个起始格式，用户格式从空开始**：

```
起始格式
┌───────────────────┐
│ GB/T 公文标准  内置 │
│ 党政机关公文格式     │
│ 学术论文       内置 │
│ 法律文书       内置 │
│ 自定义格式          │  ← 默认选中
│ 从公文格式起步，按需改│
│ 还没有保存过格式     │  ← 没有用户格式时的提示
│ 改好参数后点上方…    │
└─────────────────┬─┘
                  └─ 滚动条（内容多时才出现）
```

**没有展开/收起按钮** —— 边框加滚动条本身就足以让用户看出「这里还有更多」，
再加个展开按钮是重复设计。

面板尺寸固定 **215 × 400**（右侧参数表约 350px 高，两者接近），内容再多也不变，
只在面板内滚。鼠标停在列上时滚轮滚列，不会带动主页面；列内没得滚时自动放行给主页面。

> **必须有高度上限。** 没有上限的话面板会一直长高去容纳内容，滚动就永远不会发生。
> 上限是常量 `VIEWPORT_HEIGHT = 400`（不是"单行高 × 行数" —— 内置行带描述有 66px 高，
> 乘出来的值会比参数表还高）。

> **实现要点（四个坑都踩过）**
>
> 1. **不能靠 `pack_propagate(False)` 锁尺寸** —— 它会让高度也停止跟随子控件，
>    内容会被整片裁掉，截图上只剩一个按钮悬空。
> 2. **`wraplength` 不是最小宽度** —— 它只约束换行、不约束 Label 的最小请求宽度，
>    长名字照样把面板撑宽。改用 `CUSTOM_NAME_MAX_CHARS = 8` 截断显示。
> 3. **canvas 有默认宽度（约 378px）和默认高亮边框（2px）** —— 不显式设置，
>    前者把内容拉宽，后者让可视高度比内容矮几像素导致误判"可滚动"。
>    判定溢出时留了 `OVERFLOW_TOLERANCE = 6`。
> 4. **滚动条一出现，它的 12px 宽度就加到面板上**（pack 的布局自然会算进去），
>    实测面板会从 217 涨到 229。解法是 `_canvas_width()`：滚动条占多少，
>    canvas 就少多少，两者互补，面板总宽恒定。

### 可折叠的只剩格式区

| 折叠 | 默认状态 | 操作 |
|---|---|---|
| 格式区 | **展开** | 点「▾ 文档格式」标题 → 整块收起，**摘要行仍留在标题旁**，一屏内可见「开始处理」 |

折叠状态**不记忆**，每次启动都回到默认展开。

预设列不再有折叠态：点「＋ 存为新格式」追加一项后会**自动滚到底**让新格式可见。

### 覆盖值模型（活链接）

```
显示值 = 预设值 ⊕ 覆盖值
```

- 选择预设 → 参数表装载该预设的值，覆盖值清空
- 修改某一格 → 只记录该格为「覆盖值」，**预设本身不变**
- 改动过的行：左侧色条亮起（朱砂红），行尾 `↺` 变为可点，顶部汇总列出改了哪些字段
- 点行尾 `↺` → 恢复**该行**；点顶部「↺ 恢复全部」→ 清空所有覆盖值
- 「＋ 存为新格式」→ 把当前这套生效值存成一份新的「我的格式」

原型里覆盖值只存在内存，关掉窗口即丢弃。

### 已知的技术约束

**Win11 的 `vista` ttk 主题会忽略自定义的 `fieldbackground` / `foreground`**
（`style.lookup()` 读得回值，但原生绘制不采用）。所以覆盖值的提示**不能**靠给
Combobox 上色，本原型改用行首色条 + 顶部文字汇总，两者都不依赖 ttk 着色。
正式实现若想给单元格本身加底色，需要换用 `clam` 主题或自绘控件。

## 查看非默认状态（便于截图核对）

```bash
# PowerShell
$env:PROTOTYPE_PRESET='academic';     python prototype/layout_b.py   # 指定起始格式
$env:PROTOTYPE_DEMO='1';              python prototype/layout_b.py   # 预置四处改动
$env:PROTOTYPE_COLLAPSE='1';          python prototype/layout_b.py   # 启动即折叠格式区
$env:PROTOTYPE_SCROLL_END='1';        python prototype/layout_b.py   # 预设面板滚到底
```

`PROTOTYPE_PRESET` 可选：`custom`（默认）、`official`、`academic`、`legal`。

## 辅助脚本

| 文件 | 用途 |
|---|---|
| `_screenshot.py` | 抓取原型窗口截图（`python prototype/_screenshot.py out.png`） |
| `_check_b.py` | 无头自检，12 项：预设面板尺寸与边框 / 无展开按钮 / 面板内滚动 / 覆盖值与色条 / 段前段后 / 起始格式装载 / 格式区折叠 / 存为新格式 / 逐行与全部恢复 / 反复切换 |

`_screenshot.py` 用 `PrintWindow` + `PW_RENDERFULLCONTENT` 抓图，高 DPI 下也能正确取到
全窗口内容。注意：**不要在 `pythonw` 下用 `subprocess` 调用它**——那个环境拿不到 stdio，
会挂住。自检脚本输出含 `▸▾` 等字符，控制台需 `PYTHONIOENCODING=utf-8`。
